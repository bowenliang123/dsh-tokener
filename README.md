# dsh-tokener

[![npm](https://img.shields.io/npm/v/dsh-tokener)](https://www.npmjs.com/package/dsh-tokener)

A [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (DSH) plugin that registers [Tokener.ai](https://www.tokener.dev) as an LLM provider.

## Install

```sh
dsh plugin add dsh-tokener
```
